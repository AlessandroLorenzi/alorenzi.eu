Software is something that grows and evolves. If the code remains clean it will
be easy to maintain the base and add features to the software. Usually, a
developer spends 10 times more reading than writing the code; if the code isn't
good enough the time necessary to read and understand the code grows indefinitely
and the time needed to add new features will grow more and more and more.

![book](https://realtoughcandy.com/wp-content/uploads/2020/12/clean-code-review-robert-c-martin.jpg)

This work could seem a time-consuming activity but even washing their hands for a
doctor is a waste of time but the advantages are clear.\
We couldn't blame others to don't give us enough time. Managers look to us for
the information they need to make commitments and schedules; the users look to
us to validate the way the requirements will fit into the system.

The professional programmer shouldn't wait to clean up the code (according to
LeBlanc's Law: *Later equals never*).  
Instead, keeping the code clean should be continuous work, checking in a better
code base than the one we have checked out.
